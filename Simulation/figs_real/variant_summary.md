## 결론: 채택한 변형 없음

네 변형 중 어느 것도 채택하지 않았다. 기본 동작은 기존 `hard`(anchor 고정) 그대로다.

### soft / rel / init 은 아무 일도 하지 않았다

세 변형 모두 세트 6개·11개 구간에서 no-FK 와 소수점까지 같은 값을 낸다.
제약이 너무 약해 사실상 자유변수 그대로 풀린 것이다.

### soft-w 의 승리는 우연이었다

세트 4개 구간에서 corr-soft-w 가 2.03mm, no-FK 가 28.00mm로 크게 이기는 것처럼
보였다. 그러나 seed 별로 보면 12개 중 11개는 세 방법이 동일하고, seed 4 하나만
발산한다(no-FK 312.5mm, soft 392.8mm, soft-w 1.0mm). 그 하나가 평균을 끌어올린 것이다.

원인이 by-support 가중치인지 확인하려고 seed 4 에서 가중치를 훑었다.

| 설정 | 실효 가중치 | 결과 |
|---|---|---|
| soft λ=0.05 | 0.05 | 390mm 발산 |
| soft λ=0.1 | 0.10 | 1.08mm |
| soft λ=0.2 | 0.20 | 0.98mm |
| soft λ=0.25 | 0.25 | 393mm 발산 |
| soft λ=0.3 | 0.30 | 393mm 발산 |
| soft λ=0.45 | 0.45 | 1.19mm |
| soft-w λ=0.3 | 0.20 | 0.97mm |
| soft-w λ=0.45 | 0.30 | 393mm 발산 |

가중치를 키울수록 좋아지는 단조 관계가 없다. soft-w 를 실효 0.30 에 맞추면
균일 soft 0.30 과 똑같이 발산한다. 즉 by-support 라는 착상이 작동한 것이 아니라,
그것이 우연히 만든 실효값 0.20 이 살아남는 값이었을 뿐이다. 최적화가 두 극소점
사이에 있어 잔차 스케일이 조금만 달라져도 어디로 떨어질지가 바뀐다.

### 신뢰할 수 있는 결과

| 학습 세트 | 방법 | FK 0mm | FK 3mm | FK 9mm |
|---|---|---|---|---|
| 11개 | no-FK | 1.64 | 1.64 | 1.64 |
| | fixed-FK | **1.41** | 1.79 | 3.73 |
| | corr-hard | 1.56 | **1.60** | **1.67** |
| 6개 | no-FK | 1.91 | 1.91 | 1.91 |
| | fixed-FK | **1.51** | **1.88** | 3.78 |
| | corr-hard | 1.68 | **1.66** | **1.77** |

- corr-hard 가 no-FK 를 조금 앞선다. 6세트에서 1.66 vs 1.91 로 차이가 보인다.
- FK 가 정확하면(0mm) fixed-FK 가 최고다. 정답을 아는 상태에서 못 박기 때문이다.
- corr-hard 만 전 구간에서 1.56~1.77 로 안정적이다. fixed-FK 는 FK 9mm 에서 무너지고
  no-FK 는 FK 와 무관하지만 늘 조금 나쁘다.

### 다음에 볼 것

발산이 12번에 1번 나타났다. 이것이 재현되는 현상이면 "평균은 비슷해도 최악값이
다르다"는 결론이 가능하다. seed 를 50~100 개로 늘려 발산 빈도를 재고, anchor 고정이
그것을 막아주는지 확인하는 편이 값어치 있다.
