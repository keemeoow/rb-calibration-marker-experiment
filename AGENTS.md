# Repository figure convention

- Every new or updated Matplotlib figure must call `figure_style.apply_paper_style()` and use
  `figure_style.save_figure()` for final output.
- Use a white background, sans-serif typography, restrained semantic colors, horizontal grid lines,
  open top/right spines, and 220 dpi output. Reuse `METHOD_COLORS`, `SERIES_COLORS`, and
  `CATEGORY_COLORS`; do not introduce decorative palettes without a scientific encoding need.
- Keep unlike metrics or aggregation units on separate axes. Do not synthesize error bars,
  distributions, significance tests, or measurements absent from source data.
- State whether real-data metrics use an external ground truth or a proxy. Do not describe
  FK-proxy agreement as absolute physical accuracy.
- The visual reference is the three-image C1 real-data set generated by
  `CP_viz_c1_fk_correction.py`.
