# Calibration Results

이 문서는 `05_calibrate.py`의 결과만 사용한다. Cross-target, marker-system, OpenCV baseline 또는 외부 GT가 없어도 생성된다.

## 실행 및 데이터 계약

- Dataset: `data/session04/calib_train`
- Eligible sets: `[4, 5, 6, 7, 8, 9, 10, 11, 12]`
- Train: 119 observations / 3686 corners / 45 events
- Held-out: 35 observations / 939 corners / 9 events
- Solver: `trf`, loss `soft_l1`, f_scale `2.0 px`, residual weighting `per_corner`
- Representative matrices: seed `0`; seed 0 is the unperturbed initialization and is not selected using held-out error.

## 행렬이 생성되는 시점

| 단계 | 행렬/파라미터 | 상태와 저장 위치 |

## 최종 행렬의 의미

- `T_base_Ci = T^B_Ci`: 고정카메라 좌표를 robot-base 좌표로 변환하는 최종 extrinsic.
- `T_gripper_cam = T^G_C`: wrist-camera 좌표를 gripper 좌표로 변환하는 최종 hand-eye.
- `T_base_board`, `T_base_cube_by_set`: 공동 최적화를 연결하는 target pose이며 배포용 camera calibration 행렬이 아니다.
- 모든 4×4 행렬의 translation 단위는 meter다. 회전은 좌상단 3×3 rotation matrix다.

- A4/B1/B2의 FK covariance가 simulation prior이면 confirmatory 물리 결과가 아니다.
- 외부 GT와 robot task가 없으므로 실제 robot-base 절대 정확도는 아직 확정할 수 없다.
